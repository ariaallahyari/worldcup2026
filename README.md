## 🎯 معرفی

یک وب‌اپلیکیشن کامل برای پیش‌بینی نتایج بازی‌های جام جهانی ۲۰۲۶ ساخته شده با **PHP خالص** و **MySQL**.

کاربران می‌توانند نتیجه بازی‌ها را پیش‌بینی کنند، در صورت درستی پیش‌بینی **سکه** دریافت کنند و در **جدول رتبه‌بندی** با دیگران رقابت کنند.

اطلاعات بازی‌ها، تاریخ، ساعت و پرچم تیم‌ها به صورت **خودکار از API** دریافت می‌شود.

## 🚀 نصب و راه‌اندازی

### روش ۱ — لوکال (XAMPP)

**قدم ۱:** XAMPP را دانلود و نصب کنید
👉 [apachefriends.org](https://www.apachefriends.org)

**قدم ۲:** پوشه پروژه را داخل `htdocs` کپی کنید:
```
C:\xampp\htdocs\wc2026\
```

**قدم ۳:** Apache و MySQL را در XAMPP Control Panel استارت بزنید

**قدم ۴:** دیتابیس بسازید:
- مرورگر را باز کنید: `http://localhost/phpmyadmin`
- روی **New** کلیک کنید
- نام دیتابیس: `wc2026`
- روی **Create** کلیک کنید
- تب **Import** را بزنید
- فایل `database.sql` را آپلود و **Go** کنید

**قدم ۵:** فایل تنظیمات را ویرایش کنید:
```php
// includes/config.php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');      // نام کاربری MySQL
define('DB_PASS', '');          // رمز MySQL (در XAMPP معمولاً خالی)
define('DB_NAME', 'wc2026');
define('SITE_URL', 'http://localhost/wc2026');
```

**قدم ۶:** سایت را باز کنید:
```
http://localhost/wc2026
```

---

### روش ۲ — هاستینگ اشتراکی

**قدم ۱:** فایل‌ها را از طریق FTP (FileZilla) داخل `public_html` آپلود کنید

**قدم ۲:** در کنترل پنل هاست (cPanel):
- برو به **MySQL Databases**
- یک دیتابیس جدید بساز
- یک یوزر جدید بساز و به دیتابیس اضافه کن
- در **phpMyAdmin** فایل `database.sql` را Import کن

**قدم ۳:** فایل `includes/config.php` را ویرایش کن:
```php
define('DB_HOST', 'localhost');
define('DB_USER', 'username_dbuser');   // نام یوزر دیتابیس
define('DB_PASS', 'your_password');     // رمز دیتابیس
define('DB_NAME', 'username_wc2026');   // نام دیتابیس
define('SITE_URL', 'https://yoursite.com');
```

## ⚙️ تنظیمات

### اتصال به API

1. وارد سایت شو با: **admin** / **password**
2. برو به **پنل ادمین → تنظیمات**
3. مقادیر زیر را تنظیم کن:

| تنظیم | مقدار |
|-------|-------|
| League ID | `4429` (جام جهانی FIFA) |
| Season | `2026` |

4. روی **ذخیره** کلیک کن
5. برو به **پنل ادمین → همگام‌سازی API**
6. روی **همگام‌سازی کامل** کلیک کن

> ⚠️ **مهم:** بعد از اولین ورود حتماً رمز ادمین را تغییر بده!

---

### تنظیمات سکه

| تنظیم | پیش‌فرض | توضیح |
|-------|---------|-------|
| سکه برای پیش‌بینی دقیق | 10 | نتیجه کاملاً درست |
| سکه برای برنده درست | 5 | فقط برنده درست بود |
| ارزش هر سکه (تومان) | 1000 | نرخ تبدیل به پول |

---

### فعال‌سازی اشتراک اجباری

1. برو به **پنل ادمین → پلن‌های اشتراک** و پلن تعریف کن
2. برو به **پنل ادمین → تنظیمات**
3. گزینه **اشتراک اجباری** را فعال کن
4. کاربران برای پیش‌بینی باید اشتراک بخرند

## 🪙 سیستم سکه

```
پیش‌بینی دقیق (مثلاً 2-1 درست)  →  10 سکه
برنده درست (ایران برنده شد)       →   5 سکه
اشتباه                            →   0 سکه
```

کاربران می‌توانند سکه‌های خود را با پول واقعی **برداشت** کنند:
1. از صفحه **کیف پول** درخواست برداشت ثبت می‌کنند
2. اطلاعات بانکی وارد می‌کنند
3. ادمین درخواست را بررسی و تایید می‌کند

## 💎 سیستم اشتراک

سیستم اشتراک **زیرساخت کامل** دارد و آماده اتصال درگاه پرداخت است:

```
فعلاً: پیش‌بینی رایگان است
آینده: ادمین می‌تواند اشتراک اجباری کند
```

برای اتصال درگاه پرداخت (زرین‌پال و...):
- جدول `payments` آماده است
- جدول `subscription_plans` آماده است
- فقط باید کد درگاه به `subscription.php` اضافه شود
